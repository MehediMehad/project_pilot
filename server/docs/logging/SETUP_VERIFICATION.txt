================================================================================
MONITORING COMMANDS
================================================================================

Real-time Monitoring:
   tail -f logs/combined.log          # All logs
   tail -f logs/error.log             # Errors only
   tail -f logs/success.log           # Success logs

Search & Analysis:
   grep "pattern" logs/combined.log   # Search
   grep -c "ERROR" logs/error.log     # Count errors
   grep -E '[0-9]{4,}ms' logs/combined.log  # Slow requests

Backup & Maintenance:
   du -sh logs/                       # Check size
   tar -czf logs-backup.tar.gz logs/  # Archive
   find logs/ -name "*.log" -mtime +30 -delete  # Cleanup
